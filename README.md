# داینامیک RTL ‏(نسخه ۳)

> متن فارسی و عربی رو توی صفحه‌های وب خودش پیدا می‌کنه و راست‌چینش می‌کنه با فونت وزیرمتن — قبل از اینکه صفحه رو ببینی.

## چی کار می‌کنه

هر صفحه‌ای که باز می‌کنی رو نگاه می‌کنه و همین که متن فارسی یا عربی ببینه — توی پاراگراف، پیام چت، توییت یا حتی جایی که داری تایپ می‌کنی — همون تیکه رو راست‌چین می‌کنه و با فونت **وزیرمتن** نشون میده.

سه تا بیلد داره که منطقشون یکیه:

| بیلد | برای چی |
| --- | --- |
| `chrome/` | کروم، اج، بریو، آرک، اپرا (کرومیوم) |
| `firefox/` | فایرفاکس ۱۲۱ به بالا |
| `safari/` | سافاری ۲۶ به بالا (لود موقت) |

## نصب

### کروم / اج / بریو / آرک

1. فایل `dynamic-rtl-chrome-v3.zip` رو از صفحه [Releases](https://github.com/soroush5/Dynamic-RTL/releases) دانلود و اکسترکت کن.
2. برو به `chrome://extensions` و **Developer mode** رو روشن کن.
3. روی **Load unpacked** بزن و پوشه اکسترکت‌شده رو انتخاب کن.
4. آیکنش میاد توی تولبار. وقتی توی یه سایت فعال باشه رنگیه، وقتی نباشه خاکستریه.

### فایرفاکس

فایرفاکس معمولی افزونه امضانشده قبول نمی‌کنه. سه تا راه داری:

**راه اول — موقت (همه فایرفاکس‌ها):**

1. فایل `dynamic-rtl-firefox-v3.zip` رو دانلود کن.
2. برو به `about:debugging#/runtime/this-firefox`.
3. روی **Load Temporary Add-on...** بزن و فایل `manifest.json` داخل پوشه اکسترکت‌شده رو انتخاب کن.
4. تا وقتی فایرفاکس رو نبستی می‌مونه.

**راه دوم — دائمی (Developer Edition / Nightly / ESR):**

1. توی `about:config` گزینه `xpinstall.signatures.required` رو `false` کن.
2. اسم زیپ رو به `dynamic-rtl-firefox-v3.xpi` تغییر بده و بندازش توی فایرفاکس.

### سافاری

سافاری ۲۶ پوشه رو مستقیم لود می‌کنه، Xcode نمی‌خواد:

1. فایل `dynamic-rtl-safari-v3.zip` رو دانلود و اکسترکت کن.
2. سافاری → Settings → تب Developer → دکمه **Add Temporary Extension…** رو بزن، پوشه رو انتخاب کن و با اثر انگشت یا پسورد تایید کن.
3. توی Settings → Extensions فعالش کن با Always Allow. حواست باشه با بستن سافاری می‌پره.

## استفاده

- با کلیک روی آیکن تولبار، پاپ‌آپ باز میشه. سوییچ بالا افزونه رو برای همون سایت روشن/خاموش می‌کنه.
- حالت کلی دو تاست: *روشن همه‌جا* (پیش‌فرض) یا *خاموش همه‌جا*. سایت‌هایی که دستی عوض می‌کنی توی لیست شخصی ذخیره می‌شن.
- سایت‌هایی که خودشون فارسی هستن (مثل `lang="fa"`) به‌صورت پیش‌فرض دست نمی‌خورن، اگه خواستی با همون سوییچ روشنشون کن.
- با دکمه **Settings & custom font** میری توی صفحه تنظیمات کامل: لیست سایت‌ها، فونت و حذف فونت سفارشی.

## فونت سفارشی

پیش‌فرض **وزیرمتن** همراه خود افزونه‌ست و اینترنت نمی‌خواد. اگه فونت خودت رو می‌خوای، از تنظیمات آپلود کن (`.woff2` / `.woff` / `.ttf` / `.otf` تا ۸ مگ). فونت متغیر (Variable) بهتره چون یه فایل همه وزن‌ها رو داره.

## حریم خصوصی

افزونه هیچ تماسی به اینترنت نمی‌گیره. لیست سایت‌ها و فونت سفارشی فقط توی `chrome.storage.local` روی دستگاه خودت ذخیره می‌شن. هیچ آمار و ردیابی‌ای نیست.

## ساخت از روی سورس
